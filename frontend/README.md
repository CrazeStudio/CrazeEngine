# CrazeEngine Frontend

Minimal privacy-first search homepage.

## Deployment

Serve this directory with PHP 8+ and enable the Apache `headers` module if using `.htaccess` security headers.

The frontend currently accepts a query and safely renders it. It does **not** execute searches yet; backend integration is intentionally separate.

## Privacy

No analytics, cookies, third-party scripts, account system, or client-side tracking are included.
